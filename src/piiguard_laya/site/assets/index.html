Laya PII 가드레일 평가 결과

개인정보(PII)가 들어 있는 문장을 Laya 결정 모델이 얼마나 잘 잡아내고, 정상 문장을 얼마나 잘못 막는지 데이터셋별로 측정한 결과입니다.

페이지

대시보드평가한 모든 모델의 주요 지표를 한 표에서 비교합니다. 모델 비교모델 하나의 결과를 운영 기준·데이터셋·유형·변조 입력별로 보고, 다른 모델과 나란히 비교합니다. 예측 결과평가 문장 하나하나의 원문, 정답, 모델 점수, 판정, 모델이 고른 유형을 봅니다.

모델

모델 이름은 models/ 아래 경로입니다. base/<이름> 은 Base 모델(models/base/), trained/<이름> 은 학습된 모델(models/trained/)이고, 결과는 같은 경로의 reports/ 에 쌓입니다. 아직 평가하지 않은 모델도 함께 보여 줍니다.

모델종류기준 모델 · 출처학습 데이터만든 날평가한 날평가 데이터셋AUROC (전체)

평가용 데이터셋

datasets/<이름>/ 의 데이터셋입니다. calib 행은 모델별 임계값을 정하는 데만 쓰고, 성능은 test 행으로 측정합니다.

이름설명언어calib (PII / 정상)test (PII / 정상)라이선스 · 출처

학습용 데이터셋

training/<이름>/ 의 데이터셋입니다. 평가용과 분리되어 있고, 학습할 때 평가용 문장과 겹치는 행은 자동으로 빠집니다.

이름설명건수 (PII / 정상)출처

사용법

make prepare                                        # 기본 데이터셋 내려받기 · 변환 (datasets/, training/seed)
make bench MODEL=base/laya-multilingual             # Base 모델 평가 → reports/base/laya-multilingual/
                                                    #   models/base/ 에 없으면 처음 한 번 받는다 (MODEL 생략 시 기본값)
make bench MODEL=base/laya-multilingual DATASET=kdpii_ko   # 데이터셋 하나만
make train BASE=base/laya-multilingual NAME=r1 DATA=seed   # 학습 → models/trained/r1/
make bench MODEL=trained/r1                         # 학습된 모델 평가 → reports/trained/r1/
make site                                           # 이 페이지들 다시 만들기 (bench · train 뒤에는 자동)
